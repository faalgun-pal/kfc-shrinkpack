# KFC Shrinkpack Private Limited website

Static website (no build step, no server).

- `index.html` - the page content
- `style.css` - the design
- `script.js` - the interactive parts (product list, enquiry builder, Ask box, reviews form, page switching)
- `images/` - logo and photos

To edit contact details, product names or wording, open the file above and change the text, then commit.
Reviews are sent to a Formspree form (`REVIEW_ENDPOINT` in `script.js`).
